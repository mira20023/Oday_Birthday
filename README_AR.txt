نسخة جاهزة للنشر على GitHub Pages

1. فكّي الضغط.
2. استبدلي محتويات مستودع الموقع القديم بمحتويات هذا الملف. يجب أن يكون index.html في جذر المستودع، وليس داخل مجلد إضافي.
3. من Settings > Pages اختاري Deploy from a branch ثم main و /(root)، واحفظي.
4. انتظري اكتمال نشر GitHub Pages ثم افتحي الرابط.

لوحة التحرير: افتحي رابط الموقع ثم أضيفي #admin إلى نهايته، أو اضغطي لوحة التحكم داخل الموقع.
عدّلي النصوص وروابط GIF واضغطي تنزيل ملف التحديث. ارفعي content.json الناتج مكان الملف القديم في جذر مستودع GitHub ثم Commit changes. عند اكتمال النشر تظهر التعديلات للجميع.
لوحة التحرير متاحة محليًا لكل من يفتحها، لكنها لا تكتب على GitHub ولا تنشر أي تغييرات بنفسها. حماية النشر هي صلاحيات حساب GitHub. لا يوجد حفظ مركزي تلقائي أو رفع صور من لوحة التحرير في هذه النسخة. يمكن استخدام روابط صور HTTPS أو رفع الصور إلى المستودع وتعديل المسارات المناسبة.
الموسيقى تعمل عند الضغط على تشغيل. يحافظ الموقع على تصميم الهاتف ومعايدات ميرا وجوري والرياكشنات، بدون قصة أو لعبة.
